# Contributing

Thanks for wanting to add something! Made a thing with goome, or found a good guide or tool for it? Put it on the list.

## Adding an entry

1. Fork this repo and make a branch off **dev**.
2. Add one line to the right section in `readme.md`, at the bottom of that section. Your own project goes in **Made with goome**.
3. Open a PR against **dev**. One entry per PR.

## The format

```md
- [Name](https://link) - Short description.
```

- The description starts with a capital letter and ends with a dot.
- Say what it is, not how great it is. No "awesome", "best" or "blazing fast".
- Link the repo or the project page, not a download straight to a file.

## What gets in

- It has to work and it has to actually use goome.
- It has a README or a page that says what it is and how to run it.
- No dead links, archived repos or stuff that hasnt been touched in ages.
- No malware, cheats for online games with anti-cheat, or anything that breaks a game's rules. Read the [anti-cheat line](https://goome.wtf/docs/mods/#anti-cheat) first.

## Only readme.md

PRs should only change `readme.md`. Anything else in the PR, or a PR that isnt against dev, gets closed by a bot. Dont worry, just fix it and open a new one.

Questions go in [Discussions on c-goome](https://github.com/goome-ui/c-goome/discussions).
